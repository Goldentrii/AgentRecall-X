Intelligent Distance

The distance between you and your agents. Measured, and shortened.

You correct an agent once. AgentRecall keeps the correction as a rule with its reason, gives it to every agent you connect, and records whether it was heeded the next time it mattered.

Two ways in

The same rules and the same measurement. You choose where they live.

Connect an agent →

We host it. Sign in with GitHub and add one URL to your agent. Ready in about a minute, free, stored in Frankfurt (EU).

Run it locally →

Everything stays on your machine by default, as plain markdown files you can read. Works offline. One npx command, or let your agent install it.

How the distance gets shorter

  1. 01

    You correct an agent

    The correction becomes a rule, with its reason and where it applies. On the hosted server you approve it first.

  2. 02

    Every agent loads it

    Each session starts from the same rules and the state of your project, in Claude Code, Codex, Cursor or claude.ai.

  3. 03

    The outcome is recorded

    When the situation comes back, the rule is marked heeded or repeated.

  4. 04

    Failing rules get rewritten

    A rule that keeps being repeated is rewritten, so the next agent gets a clearer one.

What it stands for.

  • You can read it.

    Rules and project state are plain markdown, on your machine or downloadable from your hosted account at any time.

  • You approve it.

    On the hosted server, nothing an agent proposes becomes a rule until you approve it.

  • It stays yours.

    Hosted memory is stored in Frankfurt and private to your account. Local memory stays on your machine by default.

  • It is open source.

    MIT licensed. Run it yourself, or read every line of what runs here.
