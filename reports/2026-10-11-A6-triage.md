### Draft — Issue #1 (answer)

```
Good question, and sorry for the slow reply — axiom-reflex looks like convergent evolution, the
hook-interception half especially. Short answer: we write corrections at BOTH boundaries, and we
deal with the self-report skip problem at admission time rather than capture time.

Capture: on Claude Code the `ar` CLI hooks (hook-start / hook-end / hook-correction) fire from
the harness lifecycle — same philosophy as your PreToolUse route, no reliance on the agent
remembering to reflect. On hook-less hosts (Codex, Cursor, raw MCP) we fall back to agent-driven
capture via the `check` tool and session_end, per the AGENTS.md contract. One honesty note on
skip rates: we never measured the agent-path skip rate, so I can't compare it to your ~30%.
What we did measure is the hook path — a dual-blind rater study (n=59 events, two raters +
adjudicator; UPDATE-LOG §M2 "capture-leak audit", 2026-07-02) put durable-correction capture
recall at 35.3% [17.3–58.7 95% CI], i.e. roughly a 65% miss rate, with every miss being
hook-no-fire rather than misclassification.

The design answer to miss rates like that is that no single capture is trusted anyway. A correction
only activates directly when it arrives as a structured object (rule / why / applies_when);
free-text self-reports are staged to a pending-review queue. Session-end insights go through a
write-time noise gate (3.4.49), promotion into durable awareness requires 3 confirmations, and a
nightly "dream" pass (3.4.50) does admit-then-vote: ≥3 distinct (day, project) incidents within
7 days, promoted through the same 3-confirmation bar as the online path. So a skipped
self-report costs one observation, never the memory.

One more boundary you'd probably appreciate: we stopped trusting self-reported compliance too.
Since v3.4.36 a correction only counts as "heeded" if there's positive trigger evidence from
check_action that day — the default verdict is "unknown", and there's a heed-rate eval harness
(3.4.50) measuring whether surfaced corrections actually change behavior. Details for all of
this are in UPDATE-LOG.md (C3 heed instrumentation, 3.4.49 capture gate, 3.4.50 dream admission).
How does axiom-reflex score heed on the hook side? That's the metric I'd compare notes on.
```
