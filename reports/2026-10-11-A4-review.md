handler returns `formatTerse(await sessionStart({project, context}))` as `content[0].text`. The

payload. "mode=full" and "formatTerse" describe the same path. The `ar hook-start` lifecycle hook
(packages/cli/src/index.ts:1571) calls the same `core.sessionStart({project, sid})` and renders
its own terse text that mirrors formatTerse field-for-field (plus a health preamble line) —
representative, not byte-identical; the script header says exactly that. `mode=lite` /
`verbose=true` are not defaults and correctly not measured. Latency: the recall tool's default
`limit` is **10** (recall.ts, zod `.default(10)`), and the bench calls
`smartRecall({query, project, limit: 10})` — matches. Payload-vs-JSON question: `content[0].text`
IS the injected payload (the JSON-RPC envelope is transport, not context injection); measuring
the text string is correct and commensurable with the §C2 1,489-token claim.
