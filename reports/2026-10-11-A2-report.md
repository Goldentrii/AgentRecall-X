## 6. Residuals + CRLF analysis

Residual failures in the final full-chain run (core 2):

1. `N child processes x M recordOutcome('retrieved') calls` — **real bug, out of A2 scope by design**: the test comment states the failure "IS the regression signal for PR A1" (unlocked RMW race on materialized counters; the append-only ledger stays lossless at 480/480). Left for A1. Not Windows-specific.
2. `N child processes x M check() calls` — **timing/load**: passes solo; fails only while other agents run test suites concurrently (24 child processes x 20 calls under contention). Same for the cli package: the full-chain run produced 26 spawn-timeout failures (`killed: true, signal: SIGTERM` after 10s, empty stdout) under cross-agent load; two solo reruns were 293/293 green (second one fully captured). Recommendation for A8's Windows CI lane: these child-process stress tests may need a timeout bump or serial execution on shared runners.

CRLF: **no observed failure was CRLF-caused.** The working copy is CRLF (autocrlf=true), but (a) the fixture lock hash passes because bench-artifact's canonicalJson/corpus hashing canonicalizes content to UTF-8 NFC LF before hashing, and (b) no test compares raw fixture bytes against LF literals. Therefore no `.gitattributes` was added in this branch (the brief conditions it on CRLF being a cause). If the repo later wants byte-stable checkouts for all contributors, a `* text=auto` + `*.mjs/*.ts/*.js/*.json/*.md/*.yml text eol=lf` .gitattributes plus a one-time `git add --renormalize .` (which would show every text file as modified once, converting committed CRLF — there is none today — and pinning future checkouts to LF) is safe to do in a dedicated commit; nothing in the current test or bench surface depends on it.

Done-definition trace: fileURLToPath call sites all receive file: URLs (built from import.meta.url) — the TypeError path for non-file URLs is unreachable; `fs.rmSync(..., { force: true })` verified no-throw on missing dist (clean ran twice); `chmodSync` runs only after `tsc` succeeds so the target exists; `saferealpathSync` falls back to the literal input on ENOENT, and the jail then compares native-separator literals consistently. No new binaries or devDependencies introduced — all replacements are Node built-ins. No POSIX assertion weakened: the three skip classes name kernel-level features (symlink privilege, signal delivery, mode bits) Windows does not provide.
