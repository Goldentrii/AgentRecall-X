## Design decisions

**Fixture generation: hand-authored committed files (option b), not generated through core's write APIs.** Reasons: (1) every relevant writer embeds `new Date()` — journal filenames (`YYYY-MM-DD--…`), room-meta `updated`, insight `last_confirmed` — and no clock-override env exists (`AGENT_RECALL_NOW`/`AGENT_RECALL_CLOCK` not found; adding one to core was out of scope per brief), so generated output cannot be byte-stable for a lock hash. (2) The read formats are simple and verified against the readers (`listJournalFiles` filename grammar, `listRooms` `_room.json` requirement, `parseMilestoneFile` frontmatter, `CorrectionRecord`, `InsightsIndex`). Drift risk is bounded: the harness exercises the real read path, so a future format change shows up as a visible hit-rate drop, and `validate-golden-fixture.mjs` pins the structural shape. All fixture dates are ≥1 month old, so the journal tier's Ebbinghaus recency term (S=2 days, `query-memory.ts:1084`) is ≈0 for every entry and rankings cannot drift with wall-clock date — this is what makes a dated fixture deterministic without faking the clock.

**Shipped path under test:** `core.smartRecall({query, project, limit})` — the exact function the MCP `recall` tool calls (`packages/mcp-server/src/tools/recall.ts:49`) and the CLI routes to (`packages/cli/src/index.ts:581`). Called as a library (no subprocess per query).

**Scoring rule vs the 08-18 adversarial grading.** 08-18 used a human provenance check (re-read the cited source, verify the excerpt states the claim). The automatable rule: a row matches a target by (a) provenance identity — `verbatimKey.room/file` → `projects/<p>/palace/rooms/<room>/<file>`, `verbatimKey.date` → date-prefix on a `/journal/` target basename, correction `id` → `corrections/<id>.json`; insight rows have no path identity — or (b) `required_substring` over title+excerpt, case-insensitive. Stricter than 08-18 in that topical-but-wrong rows never count; weaker in that a negating quote of the substring would count (fixture content is authored so none exists). `stale_confident` (C only): top-1 carries `trap_substring` and no top-5 row carries `required_substring` — the 08-18 "confident stale-return".

**Isolation (fail-closed, the 08-18 Finding #1 class).** The harness deletes `AGENT_RECALL_SUPABASE_KEY`/`AGENT_RECALL_EMBEDDING_KEY`/`OPENAI_API_KEY`/`VOYAGE_API_KEY` before importing core; the fixture ships no `config.json` (validator asserts this), so `readSupabaseConfig()` fails closed onto the local backend; `HOME`+`USERPROFILE` are redirected to a temp dir (A2 convention) so `~/.claude/projects` (legacy journal root) and `~/.agent-recall` are unreachable; the committed fixture is copied to a temp `AGENT_RECALL_ROOT` per run and never mutated. The embeddings leg never downloads: model absent → `SKIPPED`, exit 0.

**Determinism:** `--check-determinism` runs the harness twice as child processes (clean module state, fresh temp copies) and byte-diffs the artifacts after stripping `generated_utc` only. Output: `determinism: PASS (byte-identical after stripping generated_utc)`. CI gates determinism/schema/lock-hash only — never a hit-rate value (n=26 would gate noise; same policy as the existing lane).

**Baseline verifiability:** `bench-artifact.mjs`'s `verifyBaseline` gained a `golden-retrieval/v1` branch that RECOMPUTES (not parse-only) the corpus hash from the embedded manifest and overall hit@1/hit@5 from `per_query`. `npm run bench -- --verify-baselines` covers the new dated artifacts; full `npm run bench` stays exit 0.

## What the fixture can and cannot show

**Can:** whether each structural reachability class (pipeline dir, loose rooms file, project silo, CJK tokenization, cross-language paraphrase) is retrievable on the current core; ranking behaviour between tiers on a controlled corpus; a reproducible, CI-guarded hit@k trend over core versions (the dated baselines are the time series).

**Cannot:** reproduce the private-store 30%→75%→90% trajectory (different corpus, different density/noise — the fixture is far cleaner than a year of real journals, which is why its keyword number lands near the post-fix private number rather than the 30% pre-fix one); validate ranking under real-store scale (42 files vs thousands); or replicate the 08-18 human adversarial provenance grading (approximated by the substring rule, documented above).
